# Cadastro de Produtos

## 📌 Descrição

Atividade desenvolvida em **PHP e MySQL** para cadastrar produtos por meio de um formulário.

## 🎯 Objetivo

O objetivo da atividade é praticar o desenvolvimento de formulários em HTML, a validação de dados utilizando PHP e a conexão com o banco de dados MySQL, realizando o cadastro de produtos de forma simples e segura.

## ⚙️ Funcionamento

O sistema verifica se o **nome foi preenchido** e se o **preço é um número maior que zero**. Se os dados estiverem corretos, o produto é cadastrado no banco de dados e aparece a mensagem **"Produto cadastrado com sucesso!"**. Caso contrário, uma mensagem de erro é exibida.

## 💻 Tecnologias

* PHP
* MySQL
* HTML
* XAMPP
* Visual Studio Code
